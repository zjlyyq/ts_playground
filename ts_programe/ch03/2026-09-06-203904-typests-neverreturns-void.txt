⏺ 你的 types.ts:50-52 中 neverReturns 函数已经显式标注了返回类型 never：

  function neverReturns(): never {
    throw new Error("Always throws");
  }

  当鼠标悬停时，IDE 应该显示返回类型为 never，而不是 void。如果你看到的是
  void，可能是以下原因之一：

  1. 文件未保存 — 编辑器中的内容与磁盘上的文件不一致，TypeScript
     语言服务读取的是旧版本。试试按 Cmd+S 保存后再悬停。
  2. 悬停位置不对 — 你可能悬停在了调用 neverReturns()
     的地方而非函数定义本身。不过即使是调用处，返回类型也应该是 never。
  3. TS 语言服务缓存 — 有时 VS Code 的 TypeScript 服务需要重启。按 Cmd+Shift+P →
     "TypeScript: Restart TS Server" 试试。

  never vs void 的区别：

  ┌──────┬───────────────────────────────┬──────────────────────────────────┐
  │      │             void              │              never               │
  ├──────┼───────────────────────────────┼──────────────────────────────────┤
  │ 含义 │ 函数正常返回但不返回值        │ 函数永远不会返回                 │
  ├──────┼───────────────────────────────┼──────────────────────────────────┤
  │ 示例 │ function log(msg) {           │ function throwError() { throw    │
  │      │ console.log(msg) }            │ ... } / while(true){}            │
  └──────┴───────────────────────────────┴──────────────────────────────────┘

  你的代码逻辑是正确的 — 一个总是抛异常的函数返回类型就应该是 never。

  // 旧版本 — 有显式标注

  TypeScript 的推断规则：当函数体只有 throw
  语句且没有显式返回类型标注时，TypeScript 会推断为 void，而不是
  never。要让返回类型为 never，必须显式标注。

  总结：

  ┌────────────────┬────────────────────┬─────────────┬─────────────────────┐
  │      函数      │        代码        │  推断类型   │        原因         │
  ├────────────────┼────────────────────┼─────────────┼─────────────────────┤

  │                │                    │ never       │ never               │
  ├────────────────┼────────────────────┼─────────────┼─────────────────────┤
  │ e()            │ while(true)        │ never       │ TypeScript          │
  │                │ 无限循环           │             │ 能自动推断          │

  有趣的是，TypeScript 对 while(true) 无限循环能自动推断为 never，但对只有 throw
  的函数却推断为 void — 这是 TypeScript
  的一个设计选择，所以对于抛异常的函数需要手动标注 : never。
