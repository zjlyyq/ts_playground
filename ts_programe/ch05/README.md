## 接口

类型别名和接口都是命名类型的方式。这之间有相同点也有区别。
主要有三大区别:
1. 接口右边必须是结构。
2. 接口进行扩展时，会对新接口是否可赋值给被扩展接口进行校验。
3. 接口可以进行声明合并，但类型别名如果重复会报错。

## 类既声明值也声明类型

在TypeScript中，类型和值位于不同的命名空间中。根据场合， TypeScript知道你要使用的是类型还是值。

这种根据上下文进行解析的特性十分有用，可以做一些很酷的事情，例如实现伴生类型（Companion Type）。

类和枚举比较特殊，它们既在类型命名空间中生成类型，也在值命名空间中生成值。
