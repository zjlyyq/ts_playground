### 6.3.2 Record类型
TypeScript内置的Record类型用于描述有映射关系的对象。

与常规的对象索引签名相比Record提供了更多便利：
+ 常规签名索引可以约束对象中值的类型，不过键只能使用string、 number和symbol类型。Record还可以约束对象的键为string和number的子类型。
