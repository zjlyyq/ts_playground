这段内容其实是在讲泛型 `<T>` 的**声明位置（作用域）**决定了它**何时被绑定（绑定时机）**。我把这5种情况归纳为 **“两大阵营 + 三种写法”**，你就能一眼看透了：

---

### 🎯 核心分界线：看 `<T>` 写在“签名内部”还是“类型名称外部”

#### 阵营一：泛型写在**调用签名/函数本身上**（情况 1、3、5）
**特征**：`<T>` 紧跟在函数参数列表之前（或包含在调用签名内部），不挂在 `Filter` 类型别名上。

- **绑定时机**：**每次调用函数时**绑定具体类型。
- **作用域**：仅对这一次调用生效。下一次调用，可以绑定完全不同的类型。
- **代码示例**（情况 1、3、5）：
  ```typescript
  // 情况1：完整对象类型写法
  type Filter = { <T>(array: T[], f: (item: T) => boolean): T[] }
  
  // 情况3：简写箭头函数写法
  type Filter = <T>(array: T[], f: (item: T) => boolean) => T[]
  
  // 情况5：具名函数写法
  function filter<T>(array: T[], f: (item: T) => boolean): T[] { ... }
  ```

  **使用效果**：
  ```typescript
  let f: Filter = myFilter;
  f([1,2,3], n => n > 1);  // 这次 T 是 number
  f(['a','b'], s => s === 'a'); // 下次 T 是 string（完全独立）
  ```

---

#### 阵营二：泛型写在**类型别名（或接口）的名称上**（情况 2、4）
**特征**：`<T>` 写在 `type Filter<T>` 上，属于类型声明的一部分。

- **绑定时机**：**声明变量/注解类型时**（即在使用该类型别名的那一刻）绑定。
- **作用域**：一旦绑定（比如 `Filter<number>`），整个结构里的 `T` 全部固定为 `number`，无法在调用时变更。
- **代码示例**（情况 2、4）：
  ```typescript
  // 情况2：完整对象类型写法（把 T 挂在 Filter 上）
  type Filter<T> = { (array: T[], f: (item: T) => boolean): T[] }
  
  // 情况4：简写箭头函数写法
  type Filter<T> = (array: T[], f: (item: T) => boolean) => T[]
  ```

  **使用效果**：
  ```typescript
  let f: Filter<number>; // 声明时就已经绑定了 number！
  f = (arr, fn) => arr.filter(fn); // 这里的 arr 只能是 number[]
  
  // f 无法处理 string[]，因为类型已经固定在 number 了
  ```

---

### 📝 三种格式变体（贯穿两大阵营）
图片中提到的 1/2 和 3/4 的区别，仅仅是**书写格式**不同，不影响上面说的“绑定时机”：

| 情况编号 | 格式类型 | 举例 |
| :--- | :--- | :--- |
| **1 & 2** | **完整调用签名**（大括号 `{ }` 包裹） | `type Filter = { <T>(...): ... }` |
| **3 & 4** | **简写箭头函数**（直接 `=>`） | `type Filter = <T>(...) => ...` |
| **5** | **具名函数声明** | `function filter<T>(...) { ... }` |

---

### 🧠 一句话总结这 5 种情况

| 情况 | 写法概括 | 泛型位置 | 绑定时机 |
| :--- | :--- | :--- | :--- |
| **1** | `type Filter = { <T>(...) }` | 签名内部（完整） | 调用函数时 |
| **2** | `type Filter<T> = { (...) }` | 类型名称上（完整） | 声明变量时 |
| **3** | `type Filter = <T>(...) => ...` | 签名内部（简写） | 调用函数时 |
| **4** | `type Filter<T> = (...) => ...` | 类型名称上（简写） | 声明变量时 |
| **5** | `function filter<T>(...) {}` | 函数名称上 | 调用函数时 |

**记忆口诀**：**“T 挂函数上，调用才定型；T 挂类型上，声明就锁死”**。😊
